# GrowBot — the org's physical body

astryx orgs live in tables. GrowBot gives one a body in the room: two servo legs on a
desk, a $4 Pico for a spine, and the wire for a nervous system. It is a port of
[Art of the Problem's GrowBot](https://github.com/britcruise9/GrowBot) — the open
phone↔body protocol — with one inversion: **the brain is not an API call, it is the org.**

## The chain

```
observatory GrowBot tab ──ask──►  messages row (the wire)
                                      │ LISTEN/NOTIFY
                                      ▼
                              growbot agent (a resident with a charter)
                                      │ body_act / body_stop  (MCP)
                                      ▼
                         astryx-growbot.service  :8470
                         nucleus/growbot_body.py — the full GrowBot protocol
                         (HTTP /act /stop /pose /routine /stats + WS /ws),
                         50 Hz keyframe glide engine, smoothstep easing
                                      │ "P <l>,<r>" poses over USB serial
                                      ▼
                         a plain RP2040 Pico (nucleus/growbot_firmware.py)
                         two MG90S on GP0/GP1 — boot-limp, 500 ms dead-man
```

Type "dance like you just shipped v1.0" in the observatory: it becomes a postgres row,
wakes an agent, the agent authors keyframes (it knows the body's mirror geometry from
its charter), the body glides. The reply comes back on the same thread. Every hop is a
row — auditable like everything else on the wire.

## Why USB serial

The reference GrowBot body is a Wi-Fi Pico 2 W. This port needs **no radio and no
carrier board** — useful where the Pico W and Waveshare boards simply aren't sold. The
chip stays deliberately dumb (apply the latest pose, limp when the line goes quiet);
the host runs the glide engine and speaks the standard protocol, so Brit's own
`conformance.html` passes against it unchanged — and the GrowBot tab embeds those same
conformance checks, live.

## Safety is engine-owned

The protocol's hard rules are enforced below the LLM, not requested of it: boot-limp
(an uncalibrated body never auto-moves), the 500 ms dead-man (host silence → servos
released), queue caps (3 s/step, 15 s total), instant `/stop`, and release-means-limp
(no holding torque — cool, quiet). An agent can be eloquent; it cannot be dangerous.

## Anatomy

| piece | file | claim |
|---|---|---|
| firmware (chip) | `nucleus/growbot_firmware.py` | flashed as `main.py` via mpremote |
| body host | `nucleus/growbot_body.py` + `units/astryx-growbot.service` (generated by init) | full protocol on :8470 |
| hands | `mcp/growbot/server.py` | `body_act`, `body_routine`, `body_pose`, `body_stop`, `body_stats` |
| brain | `agents/growbot.example.md` | the choreographer charter |
| face | observatory → GrowBot tab | control page + wire ask + conformance runner |

The unit only generates when a live charter grants `growbot` — shipping the example
never grows a servo service in an org that owns no robot.
